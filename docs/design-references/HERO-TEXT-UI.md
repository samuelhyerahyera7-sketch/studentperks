# Approved StudentPerks hero text and UI treatment

Use this file as the source of truth for the homepage hero wording and treatment.

Eyebrow / handwritten-style line:

Same students
brighter tomorrows

Main heading:

Student life costs less here.

Supporting copy:

Discover verified deals, events and opportunities made for South African students.

Primary CTA:

Join StudentPerks →

Secondary CTA:

Sign in

## Visual treatment

- Keep all copy as live HTML text.
- The main heading must be bold, large and left aligned.
- Add the supplied lime underline SVG beneath the emphasized part of the heading using `assets/desktop/decor/hero-green-underline.svg`.
- Do not try to recreate the underline with text-decoration. Use the SVG as a decorative layer so it matches consistently across browsers.
- Position the underline behind or directly beneath the words `costs less here.` without obscuring legibility.
- Scale the underline responsively with the heading. Preserve its hand-drawn appearance rather than stretching it vertically.
- `Same students / brighter tomorrows` should read as a small expressive handwritten-style accent above the main heading. If the exact handwritten font is unavailable, use the existing approved artwork/reference already in `assets/desktop/hero-slogan.png` rather than inventing a new script font.
- `Join StudentPerks →` is the primary lime/black CTA according to the approved desktop visual language.
- `Sign in` is the secondary action and must sit beside the primary CTA on desktop.
- Preserve the existing clean Table Mountain hero image in `assets/desktop/backgrounds/hero-table-mountain-clean.webp`.
- Do not bake any of this wording into the hero photograph.

## Responsive rules

- Desktop: keep the heading and actions grouped on the left side of the hero with the photograph visible to the right.
- Tablet: reduce heading size and allow CTAs to remain side by side while space permits.
- Mobile: stack or wrap naturally without clipping and keep the underline aligned with the emphasized heading text.
- Never allow the SVG underline to create horizontal overflow.
