Implement the desktop StudentPerks homepage using `docs/design-references/DESKTOP-HOMEPAGE.md` and `docs/design-references/public-homepage-desktop.png` as the source of truth. Read the full guide before editing code.

Use the assets in `assets/desktop/`, `assets/layered/`, `assets/sections/verify-save/`, and `assets/icons/approved/`. Do not invent images, icons, wording, businesses, offers or layouts.

Only Crates & Boxes and Custom Mugs are live businesses. Use their real database content and official assets. Treat all other brands in the visual reference as demonstration content only.

Build responsive HTML and CSS. Do not display the reference screenshots as the website. Keep all wording live and editable. Preserve authentication, database access, routes and existing working functionality. Test at 1024, 1280, 1440 and 1920 px, then test the existing mobile layouts at 360, 390 and 430 px. Run the existing tests and build before reporting completion.
