# StudentPerks interface icons

This folder is the canonical interface icon set for the StudentPerks redesign. All icons use a `24 × 24` view box, rounded line caps, rounded joins, and a two-pixel stroke.

Use these files instead of generating, drawing, or substituting new symbols. The SVGs use `currentColor`, so inline usage inherits the surrounding text colour. When used through an `<img>` element, apply colour with a CSS mask or use the default SVG appearance.

Partner and StudentPerks brand logos do not belong in this folder. Use only official, approved logo files.
